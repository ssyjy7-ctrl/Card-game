# 炸金花

一个可直接打开的静态网页卡牌游戏，包含德州扑克、炸金花、憋王八三种玩法。

## 本地试玩

双击 `index.html` 即可打开主菜单并选择玩法。

## 当前玩法

- 德州扑克：两张底牌，五张公共牌。
- 炸金花：三张手牌直接比牌。
- 憋王八：一副牌去掉小王，只留大王；发牌后自动打出对子，轮到玩家时必须手动点下一家的背面牌抽牌，最后拿着大王的人输。

## 发给别人试玩

把以下文件一起打包发送给对方：

- `index.html`
- `styles.css`
- `game.js`
- `turtle.html`
- `turtle.css`
- `turtle.js`

对方解压后双击 `index.html` 即可玩。
